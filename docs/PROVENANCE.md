The Git release contains the three immutable annotation sources, site definitions, fixed policies, derived scoring geometry, input manifests, selected scientific tests and compact final results. Its `provenance/FILE_MANIFEST.json` hashes the published files. The experiment ledger indexes completed runs without publishing correspondence or local editing history. Historical machine records can retain original source paths; those paths identify the archived source location and are not current execution instructions.

The complete local package preserves original inputs, the upstream source/checkpoint, both adapted checkpoints, final derived outputs, raw prediction archives, scientific receipts, final documents, original requirements and cited reference PDFs. It uses the original sibling layout (`Starter_Kit`, `Xi_Zhang_Benchmark`, `baselines`, `SegmentAnyTree`) so relative input paths remain meaningful. Local package files are ordinary independent files; APFS cloning may share physical blocks until a copy changes.

Old working annotation exports, weekly communication, document renders/editing scripts, caches, virtual environments and duplicated compressed/extracted copies are excluded. Original blind annotations and distinct reported scientific experiments are retained as necessary evidence, even when they precede the final reference. Historical source hashes and original archive hashes are preserved; package manifests describe the curated payload and do not imply excluded archive files are present.

The original historical producer commit, mask identity and polygon export remain incompletely established. The author lock identifies the analysis reference and its approval authority. Weak targets do not supply independently checked three-dimensional truth.
